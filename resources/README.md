# 资料索引

`resources/` 用于集中保存研究、复现和实现过程中发现的、值得反复查阅或复用的参考资料，同时保留项目早期研究与工程原始记录。这里可以收录尚待验证的线索，但不作为当前方案、任务状态或实验结论的事实来源。

## 收录范围

- 论文、代码仓库、数据集、benchmark、工具、服务和技术文档的索引或阅读笔记；
- 环境搭建、依赖兼容、数据处理、训练评测和故障排查的外部参考；
- 对后续复现或实现有帮助的示例、配置说明、设计线索与历史记录。

新增资料使用简短、可辨识的文件名，并在本页登记其来源、用途和验证状态。小型文本资料可以直接保存；模型、数据集、wheel、日志等大型产物仍放在规定的共享存储中，`resources/` 只记录索引和获取信息。不得保存密钥、内部凭据或来源和许可不明的内容。

## 使用与沉淀

1. 发现可能有用的资料时，保存链接、来源、用途、适用项目和必要摘要，方便后续检索与复用。
2. 使用前对照当前论文、固定代码、服务器环境和实际实验重新验证。
3. 项目专属执行事实写入 `docs/reproductions/<project>.md`，并按需链接本目录资料。
4. 经验证且可跨项目复用的经验写入 `docs/reproductions/common/`，同时保留原始资料来源。
5. 只有影响研究主线或方法选择的结论，才更新[研究计划](../docs/research-plan.md)或[复现计划](../docs/reproduction-plan.md)。

当前总览以[项目 README](../README.md)为准，执行状态以[任务清单](../docs/tasks.md)为准。现有两份早期记录保留历史原貌，不在其中继续维护当前任务。
