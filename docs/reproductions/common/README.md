# 跨项目共享经验

本目录按需记录多个复现项目之间可复用的经验与工作记忆，不替代 `docs/reproductions/<project>.md` 中的具体执行记录。

## 记录原则

- 按主题创建短文件名，例如 `environment.md`、`data-services.md`、`training.md`、`evaluation.md` 或 `troubleshooting.md`；无需预建空文件。
- 只提炼已验证的通用做法，并注明来源项目、适用项目、软件或硬件前提及验证范围。
- 项目专属命令、路径、结果、失败和未验证判断仍写在对应项目文件中；共享文件通过链接引用证据，避免复制和版本分叉。
- 不记录密钥、完整日志或大型产物；不同项目存在冲突时保留各自条件，不强行统一。

## 最小条目

```markdown
## <经验标题>

- 来源记录：
- 适用项目：
- 前提与版本：
- 结论或操作要点：
- 验证范围：
- 限制：
```
