# 单项目复现记录

每开始一个项目，在本目录创建 `<project>.md`。目标是跑通核心流程、完成 1–2 个重要实验并记录经验，不要求覆盖论文全部实验。

## 最小模板

```markdown
# <Project> 复现记录

> 状态：待开始 / 进行中 / 已完成 / 阻塞
> 论文：
> 仓库：
> Commit：

## 1. 复现目标

- 关键实验 1：
- 关键实验 2（可选）：

## 2. 论文设定

- 数据与划分：
- 模型：
- 环境与依赖：
- 训练：
- 评测：
- 硬件：

## 3. 本地准备

- 离线资产：
- 服务：
- 配置差异：

## 4. 执行记录

- 命令：
- Checkpoint：
- 日志：

## 5. 结果

## 6. 偏差与问题

## 7. 结论与项目价值

## 8. 下一步
```

只记录实际执行内容。计划、论文报告值和本地结果必须分开标注；未选择的论文实验无需逐项记录。完成或阻塞时同步更新 [任务清单](../tasks.md)。
