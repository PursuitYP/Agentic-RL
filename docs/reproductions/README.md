# 复现记录

每个项目在开始 L0 核验时创建 `<project>.md`。记录应让后来者能够确认复现范围、重跑关键命令、理解结果差异并从中断处继续；不要求覆盖论文全部实验。

## 目录约定

- `<project>.md`：记录该项目特有的论文设定、版本、环境、命令、进度、结果、偏差和问题。
- [`common/`](common/README.md)：按主题记录已验证且可跨项目复用的环境、数据、服务、训练、评测和排错经验。

项目记录是具体执行事实的来源；共享文件只提炼通用做法，并链接对应项目记录，不替代原始命令、结果和问题。
