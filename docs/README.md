# 文档导航

## 文档职责

| 入口 | 负责回答 | 内容性质 | 更新时机 |
| --- | --- | --- | --- |
| [项目 README](../README.md) | 项目做什么、目前在哪个阶段 | 稳定总览 | 目标、阶段或仓库结构变化时 |
| [任务清单](tasks.md) | 现在做什么、下一步是什么 | 当前状态的唯一入口 | 任务开始、完成、阻塞或改优先级时 |
| [研究计划](research-plan.md) | 为什么做、研究什么、如何验证 | 研究问题与方法计划 | 研究问题、方案或证据边界变化时 |
| [复现计划](reproduction-plan.md) | 12 个项目为何复现、怎样验收 | 预期流程与价值分析 | 论文/代码事实或复现范围变化时 |
| [复现记录](reproductions/README.md) | 实际如何运行、得到什么结果 | 项目级执行事实 | 每次准备、运行、评测或排错后 |
| [共享经验](reproductions/common/README.md) | 哪些经验可以跨项目复用 | 有来源和边界的验证结论 | 通用做法得到验证或失效时 |
| [资料索引](../resources/README.md) | 有哪些可复用参考与历史线索 | 参考资料，可包含待验证内容 | 发现、更新或验证有用资料时 |

论文 PDF 位于 [`related-papers/`](../related-papers/)，固定 commit 的官方代码位于 [`related-projects/`](../related-projects/)。

## 建议阅读路径

1. 先读[项目 README](../README.md)和[任务清单](tasks.md)，确认目标、阶段与当前行动。
2. 做研究设计时读[研究计划](research-plan.md)；做论文复现时读[复现计划](reproduction-plan.md)。
3. 实际执行以对应的 `docs/reproductions/<project>.md` 为准，需要通用工程经验时再查 `common/`。
4. 查找论文、数据、工具、实现或历史线索时使用 `resources/`；其中待验证内容不能直接作为实验结论。

## 维护原则

- 总览、计划、任务状态和实验事实各自只维护一份，其他文档使用链接引用。
- 明确区分论文报告、代码现状、本地结果、推断、假设和计划。
- 项目专属事实保留在项目记录；共享经验必须注明来源、适用条件和验证范围。
- 文档随研究和实验及时更新，确保可总览、可回顾、可理解并能从中断处恢复。
