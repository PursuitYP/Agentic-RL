# 文档导航

## 核心文档

| 文档 | 用途 | 更新时机 |
| --- | --- | --- |
| [研究计划](research-plan.md) | 项目目标、研究问题、方法假设与证据边界 | 研究方向或核心设计变化时 |
| [复现计划](reproduction-plan.md) | 12 个项目的核心流程、关键实验和价值分析 | 发现论文/代码差异或调整复现方案时 |
| [任务清单](tasks.md) | 当前阶段、优先级和完成状态 | 每次任务开始、完成或阻塞时 |
| [复现记录模板](reproductions/README.md) | 单项目环境、命令、结果和偏差的记录格式 | 开始或推进具体复现时 |

## 资料入口

- [前期资料索引](../resources/README.md)：历史研究与工程笔记；
- [相关论文](../related-papers/)：12 篇论文 PDF；
- [相关项目](../related-projects/)：固定对应官方仓库 commit 的 Git submodule。

## 阅读顺序

1. 从项目 [README](../README.md) 了解目标和仓库结构；
2. 阅读 [研究计划](research-plan.md) 理解研究主线；
3. 阅读 [任务清单](tasks.md) 确认当前工作；
4. 执行复现时查阅 [复现计划](reproduction-plan.md) 和对应单项目记录；
5. 需要历史背景或实现线索时再查阅 `resources/`。

## 维护规则

- `README.md` 只保留稳定总览，不承载实验过程；
- `tasks.md` 是任务状态的唯一入口；
- 每个复现项目使用 `docs/reproductions/<project>.md` 记录环境、命令、结果和偏差；
- `resources/` 为前期资料，不作为当前事实或最终结论；
- 规划、进行中、已完成和已验证必须明确区分；
- 文档应随研究和实验及时更新，确保工作可总览、可回顾、可理解、可恢复。
